# Varainsiirtoverolain (931/1996) kommentaari

Kommentaari suomalaiseen säädökseen: **Varainsiirtoverolaki 29.11.1996/931**. Kommentaari kattaa **85 pykälää** (1–9 luku, mukaan lukien kumotut ja määräaikaisina päättyneet pykälät sekä voimaantulo- ja siirtymäsäännökset) **3 kommentaarin luvussa**; kunkin pykälän kohdalla esitetään säännöksen sanamuoto sellaisenaan ja sen jälkeen kommentaari.

Tekstin tila: Finlexin ajantasainen lainsäädäntö (ajantasaistettu **17.4.2026**, versio 20260288; viimeisin lähteessä mainittu muutossäädös 17.4.2026/288, voimaan 1.5.2026).

## Menetelmä

Kommentaari on laadittu **yksinomaan paikallisten aineistojen perusteella** (Finlexin avoimen datan ajantasainen säädösteksti ja sen metatiedot), ilman kaupallisia oikeudellisia tietokantoja. Säännösten sanamuoto on siirretty lähteestä koneellisesti ja sanatarkasti. Lähteen ajantasaistusmerkinnät, aiemmat sanamuodot ja muutossäädösten tiedot esitetään lähteen huomautuksina. **Oikeuskäytäntö ei sisälly tähän versioon** — se lisätään erillisessä vaiheessa.
